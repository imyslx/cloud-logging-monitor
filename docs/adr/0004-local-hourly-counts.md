# ADR-0004: 件数は種類×1時間で手元に残す。ローカル完結・外部ライブラリなし

- 状態: 採用
- 日付: 2026-11-25

## 背景

Cloud Logging の保持は30日。それより前の傾向を見るには、手元に残すしかない。ログの本文には顧客のデータが混ざりうるので、外には出したくない。

## 決定

- 手元に残すのは、種類×1時間ごとの件数、種類ごとの本文（伏せた後）・初出・最終・最近の実例3件、カーソル。90日を過ぎたら捨てる
- 置き場は `~/.prod-log-dash/state.json`。取り込みのたびに丸ごと書き直す（一時ファイルに書いてから置き換える）
- サーバーは `127.0.0.1` だけで待ち受ける。認証は持たない
- Node.js の標準モジュールだけで書く。画面も素の HTML / CSS / JS

## 理由

- 量が小さい。60種類×24時間×90日でも13万の数で、JSON で数 MB
- 本文そのものは実例の3件しか残さないので、顧客のデータが手元に溜まり続けない
- 依存が無ければ、`git clone` してすぐ動く

## 見直す条件

- 種類が数千を超えて、丸ごとの書き直しが重くなったら、`node:sqlite` などに移す
- 複数の端末で同じ画面を見たくなったら、Tailscale などの閉じたネットワークの中で、ほかの端末のダッシュボードから取りに行く形を足す（その場合は認証も足す）
